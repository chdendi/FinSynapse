## 一、NVIDIA 芯片技术路线图

### 1.1 架构演进全景

| 架构 | 时间窗口 | 制程 | 显存 | FP4 算力 | 代表产品 |
|------|---------|------|------|---------|---------|
| Hopper | 2022-2024 | TSMC 4N | HBM3/HBM3E | 4-8 PF | H100/H200 |
| Blackwell | Q4 2024-2026 | TSMC 4NP | HBM3E (192GB) | 20 PF (GB200) | B100/B200/GB200 |
| Blackwell Ultra | 2H 2025-2026 | TSMC 4NP | HBM3E (288GB) | ~35 PF | GB300 |
| Rubin | 2H 2026-2027 | TSMC 3NP (3nm) | HBM4 | 50 PF | Vera CPU + Rubin GPU |
| Rubin Ultra | 2027-2028 | TSMC 3NP | HBM4 (16-Hi) | 100 PF | Kyber 机架 |
| Feynman | 2028+ | 预计 N2 | HBM4+ | 未定 | Rosa CPU + 3D 堆叠 GPU |

### 1.2 关键技术趋势

1. **制程推进**: 4NP → 3NP(3nm) → 预计 N2，接近物理极限
2. **封装升级**: CoWoS-L → 3D 堆叠，封装产能是当前核心瓶颈
3. **内存演进**: HBM3E(8层) → HBM4(16层)，单 GPU 内容量快速翻倍
4. **功耗剧增**: 700W(H100) → 1200W(B200) → 3000W+(Rubin Ultra)，液冷从"可选"变"必选"
5. **发布节奏**: 从两年一代加速到一年一代
6. **纵向整合**: 自研 CPU (Grace → Vera → Rosa) + GPU + 网络(NVLink/Mellanox)，全栈绑定

## 二、供应链分层拆解及增速

### 2.1 供应链全景

```
NVIDIA 设计
  ├── 晶圆代工: TSMC 4NP → 3NP → N2
  ├── 先进封装: TSMC CoWoS-L (核心瓶颈)
  ├── HBM 内存: SK Hynix (53%) / Samsung / Micron
  ├── ABF 基板: Unimicron / Ibiden / Shinko
  ├── 光模块: Innolight / Coherent / Eoptolink
  ├── 连接器/线缆: Luxshare / Amphenol
  ├── 液冷散热: CoolIT / Vertiv / Delta / AVC / Auras
  ├── 电源/VRM: Delta / Murata / MPS
  ├── 服务器组装: Foxconn / Quanta / Wistron / SMCI
  └── 测试: Advantest / Teradyne / ASE
```

### 2.2 各环节增速预估 (2025-2027 CAGR)

| 供应链环节 | 预估 CAGR | 核心驱动力 |
|-----------|----------|----------|
| 液冷散热 | **80-120%** | 单 GPU 700W→3000W，液冷从可选变强制 |
| HBM 内存 | **80-100%** | HBM3E→HBM4升级，容量翻倍，单价 3-5x DDR5 |
| CoWoS 封装 | **50-70%** | GPU 颗数增长，TSMC 急速扩产 |
| 服务器组装 | **50-70%** | GB200 NVL72 单机架约 $3M，单元价值飙升 |
| 光模块/网络 | **40-60%** | 400G→800G→1.6T，NVLink 7 带宽激增 |
| 电源/VRM | **30-45%** | 单 GPU 功耗翻倍，高端 VRM 价值量上升 |
| 晶圆代工 | **25-35%** | 先进制程高价，wafer 面积增大 |
| 测试设备 | **25-35%** | 封装复杂度增加，测试时间延长 |
| PCB/基板 | **15-25%** | GPU 接近光罩极限，高层数 PCB 需求 |

## 五、"最不容易被 AI 革命颠覆"的核心资产逻辑

新一轮科技革命（AI + 算力爆炸）中，最能抵抗颠覆的环节须具备以下特征：

1. **物理不可替代**: 需要实体制造、物理空间、物质材料，无法被软件/AI 取代
2. **极长认证周期**: 供应商切换成本极高（光学/PCB/封装需 1-3 年验证）
3. **规模壁垒**: 需要巨额资本开支和长期建设，新进入者无力颠覆
4. **技术独占性**: 少数玩家掌握核心工艺，技术曲线非线性
5. **政策/地缘保护**: 监管或地缘风险构成天然护城河

### 排名前十

| 排名 | 公司 | 核心壁垒 | 不可替代性 |
|------|------|---------|----------|

## 六、关键风险

### 6.1 系统性风险

1. **AI 泡沫**: Big Tech 2026 年联合 ~$650B+ CapEx，若 AI 收入不达预期，全链条反噬
2. **地缘政治**: 中美科技脱钩是最大变量；美国可能进一步限制中国公司参与 NVIDIA 供应链
3. **技术替代**: 定制 ASIC (Google TPU、AWS Trainium、Broadcom 定制) 可能侵蚀 NVIDIA GPU 份额
4. **制程瓶颈**: 3nm→2nm→1nm，物理极限逼近，摩尔定律放缓

### 6.2 中国供应链最大短板

| 环节 | 现状 | 差距 |
|------|------|------|
| **HBM 内存** | Hynix/Samsung/Micron 三家垄断 | CXMT 落后 5+ 年，完全没有 HBM3E 能力 |
| **EUV 光刻** | ASML 独供，中国完全无法获取 | 限制了 SMIC 制程上限 |
| **高端 EDA/IP** | Synopsys/Cadence/ARM 主导 | 中国几乎无替代方案 |
